# 📚 Gerenciador de Tarefas

Um aplicativo web moderno para gerenciar tarefas, eventos e anotações de estudantes.

## ✨ Funcionalidades

### 📝 Tarefas
- Adicionar tarefas com prioridade (Baixa, Média, Alta)
- Associar matérias (Matemática, Português, História, Geografia, Ciências, Inglês)
- Definir prazos com datas
- Marcar tarefas como concluídas
- Excluir tarefas

### 📅 Eventos
- Criar eventos (Provas, Trabalhos, Apresentações, Reuniões)
- Definir datas para eventos
- Eventos ordenados automaticamente por data
- Excluir eventos

### 📌 Anotações
- Salvar anotações por matéria
- Anotações organizadas por tema
- Anotações ordenadas por data (mais recentes primeiro)
- Excluir anotações

## 🛡️ Segurança

- ✅ Proteção contra XSS com escape de HTML
- ✅ Validação de entrada em todos os formulários
- ✅ Dados salvos localmente no navegador

## 🚀 Como Usar

1. Abra o arquivo `index.html` no navegador
2. Navegue entre as abas (Tarefas, Eventos, Anotações)
3. Use os formulários para adicionar novos itens
4. Os dados são salvos automaticamente no localStorage

## 🎨 Tecnologias

- HTML5
- CSS3 (com Gradientes e Animações)
- JavaScript Vanilla
- LocalStorage para persistência de dados

## 📱 Responsividade

O aplicativo é totalmente responsivo e funciona em:
- Desktop
- Tablet
- Mobile

## 📦 Arquivo de Dados

Todos os dados são salvos localmente no navegador usando `localStorage`. Seus dados não são enviados para nenhum servidor.
